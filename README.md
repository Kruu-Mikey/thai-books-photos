# thai-books-photos

Public copies of the cropped photos in `Kruu-Mikey/thai-books` (`assets/photos/`),
so Google Docs can fetch them by web address when the lessons are imported.
Each Doc keeps its own copy once imported.

This repo holds only image files. Lessons, tools, credits and licences live in
`thai-books`; credits are in each book's Photo Credits doc. Files larger than
2000 px on their long side are scaled down to 2000 px; nothing is re-cropped.
